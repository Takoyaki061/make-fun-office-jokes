One line about office life, under 200 characters — written by `main.py`
(standard library only, deterministic) to `/output/entry.txt`:

> Per my last email, the server room is still on fire — and per this email, I've stopped clarifying that "fire" is literal.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The program writes exactly one joke (121 characters), checks it against the
gate (1–199 characters, not only whitespace), and exits non-zero if the
check fails.
